如何交互

  1. 在 Claude Code 中提问。需要公式或图的讲解会写到本站，终端里给出链接和简短摘要。
  2. 对某页或某节有疑问，可以在 GitHub 上提交 issue，注明页面和小节。在 Claude Code 中请 Claude 查看网站反馈时，它会读取 issue、在 issue 中回复，并把需要的修改写进页面。
  3. 每次更新都同时维护中文和英文，并在下面追加一条记录。
