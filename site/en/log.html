A dated record of each question, the page that holds the answer and its current status. The page text itself is authoritative.

How to interact

  1. Ask in Claude Code. Explanations that need equations or figures are written to this site, and the terminal reply gives the link and a short summary.
  2. For questions about a page or section, you can open an issue on GitHub, naming the page and section. When asked in Claude Code to check the website feedback, Claude reads the issues, replies in them, and writes any required changes into the pages.
  3. Every update maintains the Chinese and English versions together and appends an entry below.

    Question: We no longer use the Holstein model in this project, because the phonon dispersion must no longer be constant; so should it be called the Peierls model? Follow-up decision: rename it dispersive-Holstein and drop "claude".

    Answer: Not a Peierls model. Holstein and Peierls distinguish how the electron couples to the lattice, and dispersion is an independent choice; the model of this project is a Holstein-type model with dispersive optical phonons, see Theory notes, Section 2.1. The repository and website are renamed dispersive-Holstein, and the old address is no longer served.
